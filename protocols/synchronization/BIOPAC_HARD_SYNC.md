
# SPEC-P6 BIOPAC Hardware Synchronization

## Overview

SPEC-P6 provides hardware synchronization between the wearable sensor network and the BIOPAC reference acquisition system.

Synchronization is performed through a hardware trigger generated by the Coordinator and provided to the BIOPAC system as a digital pulse.

The synchronization architecture is:

```text
                    Host Computer
                         |
                    Serial / USB
                         |
                         v
                   Coordinator
                    ESP32
                         |
              +----------+----------+
              |                     |
           ESP-NOW               TTL trigger
              |                     |
              v                     v
        Sensor Nodes              BIOPAC
        Node 1, 2, 3
```
Synchronization components

The synchronization procedure involves three main components:

SPEC-P6 Sensor Nodes.
SPEC-P6 Coordinator.
BIOPAC reference acquisition system.

The Sensor Nodes generate timestamped physiological and inertial measurements.

The Coordinator receives the measurements and provides the hardware trigger used to mark the acquisition in the BIOPAC system.

Sensor Node timestamps

Each measurement sample generated by a Sensor Node contains a timestamp in microseconds:
```cpp
timestamp_us
```
The timestamp is generated locally by the Sensor Node and is associated with the individual measurement sample.

The timestamp is transmitted together with the PPG and inertial measurements.

Acquisition synchronization

The acquisition software communicates with the Coordinator through a serial interface.

The Coordinator controls the Sensor Nodes through ESP-NOW.

The general acquisition sequence is:

```text
Host computer
      |
      | acquisition command
      v
Coordinator
      |
      | ESP-NOW
      v
Sensor Nodes
      |
      | measurement data
      v
Coordinator
      |
      | serial data
      v
Host computer
```
BIOPAC hardware trigger

The Coordinator provides a dedicated digital output used to generate the BIOPAC synchronization trigger.

During an acquisition, the host software sends the trigger command to the Coordinator through the serial interface.

The Coordinator then generates the digital pulse that is recorded by the BIOPAC system.

The trigger therefore provides a hardware event that can be identified in the BIOPAC recording and associated with the SPEC-P6 acquisition timeline.

Trigger sequence

The synchronization sequence implemented by the acquisition software follows the following logic:
``` text
1. Sensor Node calibration
          |
          v
2. Acquisition initialization
          |
          v
3. Sensor Node data reception
          |
          v
4. Synchronization point reached
          |
          v
5. Coordinator receives trigger command
          |
          v
6. Coordinator generates BIOPAC TTL pulse
          |
          v
7. SPEC-P6 and BIOPAC continue recording
```
Software-to-hardware synchronization

The acquisition software communicates with the Coordinator using the serial interface.

The software monitors incoming Sensor Node timestamps and determines the appropriate synchronization point during recording.

The BIOPAC trigger is then generated through the Coordinator hardware output.

The acquisition software records the timestamp associated with the trigger event for subsequent temporal alignment.

Temporal alignment

SPEC-P6 measurements are timestamped at the Sensor Node level.

The BIOPAC system records the hardware trigger as a digital event.

The synchronization procedure therefore provides a reference point between:
``` text
SPEC-P6 timestamp
        |
        | temporal alignment
        v
BIOPAC trigger event
```
This allows the SPEC-P6 and BIOPAC recordings to be aligned during subsequent data processing.

Trigger state

The acquisition software represents the BIOPAC trigger state as:
``` text
TRIG: LOW
```
during the inactive state and:
``` text
TRIG: HIGH
```
when the synchronization pulse is activated.

After the synchronization event, the trigger is returned to its inactive state.

Synchronization data

The acquisition software stores the timestamp associated with the BIOPAC synchronization event.

This information can be used during subsequent analysis to determine the temporal relationship between SPEC-P6 and BIOPAC recordings.

Important distinction

The BIOPAC hardware trigger establishes a synchronization reference event between the two acquisition systems.

It does not imply that the individual Sensor Node clocks are physically identical or that the wireless communication latency is zero.

The synchronization accuracy and temporal drift of the complete system must therefore be experimentally characterized.

Experimental validation

The following parameters should be experimentally evaluated before publication:

Trigger timing error.
Inter-node temporal alignment.
Trigger-to-timestamp offset.
Temporal drift during acquisition.
Repeatability of the synchronization event.
